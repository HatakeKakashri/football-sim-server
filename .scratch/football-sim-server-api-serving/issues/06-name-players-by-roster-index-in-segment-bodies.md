# 06: Name players by roster index in the segment bodies

**What to build:** The manifest already lists the 22 players with their fixture ids, so a segment body does not have to repeat the id of every player in every frame — it can name the player by the roster index the manifest publishes. Change the segment body so that a frame names each player by their roster index; the manifest's roster row is the mapping from index to id. This is a change to the wire format, so the format version is bumped, PRD §10.3 is rewritten, the sample payloads are regenerated and the pinned segment hashes move with it. The manifest itself is unchanged apart from its format version, and the build id still covers the fixture, the format version and every segment's uncompressed hash, so a URL published under the old format keeps meaning what it meant.

Naming players by index is not enough on its own to get a match under the transfer budget — that is ticket 07 — but it is the half of the change that needs no clever encoding, and it is the change that makes the frames cheap to hold (ticket 05).
